## Fonctionnalités réellement disponibles

### Tableau de bord

- quatre indicateurs fictifs : équipe, permanences, couverture et absences ;
- trois prochaines affectations de démonstration ;
- graphique illustratif de répartition par type.

### Personnel

- six profils fictifs au chargement ;
- recherche par nom ;
- filtres Tous, Actifs et Absents ;
- bouton d’ajout simulé et import Excel simulé.

### Planning des permanences

- calendrier mensuel d’août 2026 ;
- neuf affectations fictives initiales ;
- déplacement local d’une affectation par glisser-déposer ;
- ajout local d’une permanence ;
- génération, validation et réinitialisation de la proposition ;
- affichage simulé de l’historique des versions ;
- exports PDF et Excel simulés.

### Absences et exemptions

- liste de trois absences fictives ;
- ajout local d’une absence ;
- alertes de démonstration ;
- deux exemptions fictives et ajout simulé.

### Services opérationnels

- filtrage de six cellules fictives ;
- affectations génériques par créneau ;
- génération locale de la journée ;
- exports PDF et Excel simulés.

### Rapports

- graphique illustratif de charge ;
- répartition fictive par type ;
- journal d’audit simulé ;
- commandes d’export simulées.

### Interface

- navigation entre six vues ;
- sélection de site fictive ;
- menu responsive ;
- boîtes de dialogue et confirmations locales.

## Limites de la démonstration

La démo ne possède ni authentification réelle, ni backend, ni base de données et ne génère aucun fichier réel. Les modifications disparaissent au rechargement. Les règles privées du produit ne sont pas reproduites.

## Publication GitHub Pages

Le site est publié depuis la branche `main`, dossier `/ (root)`, avec **Deploy from a branch**. `index.html` contient l’étude de cas et `demo.html` la démonstration.

```bash
git add .
git commit -m "Mettre à jour la vitrine Garde Tranquille"
git push
```
