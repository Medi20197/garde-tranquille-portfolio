# Garde Tranquille — aperçu portfolio

Présentation publique d’une application web de gestion de planning et de permanences.

> Ce dépôt est volontairement limité à une vitrine statique. Le code métier, les règles
> opérationnelles, les données, les configurations et l’identité de l’établissement ne
> sont pas publiés.

## Aperçu

La vitrine présente les grands objectifs du produit :

- centraliser les plannings et les absences ;
- faciliter la préparation des permanences ;
- visualiser les indicateurs utiles ;
- exporter des documents de travail ;
- gérer plusieurs profils d’accès.

Toutes les informations visibles dans la démonstration sont fictives.

## Technologies du produit privé

React, TypeScript, Node.js, Express, MongoDB et Docker.

## Consulter la vitrine

Ouvrez `index.html` pour consulter l’étude de cas. La page `demo.html` propose une
démonstration interactive distincte utilisant exclusivement des données fictives.
